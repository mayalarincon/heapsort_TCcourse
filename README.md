# Heapsort verification in PVS

This repository will maintain our progress on the verification of the algorithm heapsort. 

The starting point is the formalization of heapsort in the Nasa library theory [sorting](https://github.com/nasa/pvslib/tree/master/sorting).

Nice and simplified explanation of heapsort are available in classical textbooks on algorithm analysis as Cormen, Leiserson, Rivest and Stein book.
